# 可选计分器输入

在项目根目录运行 `python3 scripts/score.py examples/annotations-01.json`。

输入是一个 JSON 对象，只有 `units` 数组。每个单元包含唯一非空 `id`、原文短引 `quote`、含 J/M/A/R/T/V 六个整数的 `scores` 对象。所有分值在 0–4 之间。先由模型或人工按 rubric 完成分段、立场判断和语义标注，再交给脚本。

两个随包 JSON 分别对应示例 01 和 02。空数组返回 score=null 和“无法评分”。重复 id、缺项、非整数和越界值会报错。

输出 means 为原始均值，contributions 为各项加权贡献；V 的贡献已经反向处理。raw_score 是未取整结果，score 为四舍五入整数。计算过程中使用精确分数，显示值转为小数。

脚本不联网、不保存原文、不判断标注是否合理，也不核查引文是否忠实；正常输出不回显原文。语义证据和校准理由必须由助手另外提供。
