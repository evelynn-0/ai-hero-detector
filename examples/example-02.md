# 示例 02：具体表达、低分与误伤校准

示例为自写虚构材料及参考标注；数值没有进行外部核验。

## 输入

```text
/detect
在上周的内部测试中，工单助手只生成回复草稿，由客服确认后发送；同一组 40 条历史工单的平均处理时间从 10 分钟变为 8 分钟，质量尚未评估，也未验证线上收益。
```

## /detect 参考输出

**范围**：一段内部测试描述。  
**有效主张**：1，U1 的流程、样本、时间比较与局限共同支持“此次测试中处理时间下降”这一有限结论。  
**指数：0/100 — 话术信号较少。**  
**判断信心：高（仅对表达归类）；数据真实性未核验。**

| 维度 | U1 原始分 / 4（也是均分） | 加权贡献 | 依据 |
|---|---:|---:|---|
| J | 0 | 0 | “只生成回复草稿，由客服确认”交代了实际动作 |
| M | 0 | 0 | 无类比替代机制 |
| A | 0 | 0 | 无落后或淘汰威胁 |
| R | 0 | 0 | 无身份背书替代论证 |
| T | 0 | 0 | 限于“上周的内部测试”，未宣称时代转折 |
| V | 4 | 0（信息缺口） | 有具体流程、同组 40 条样本、10 到 8 分钟的比较和质量/线上收益局限，可据此设计复核 |

U1 完整标注：`J=0, M=0, A=0, R=0, T=0, V=4`。按公式得到 0。

**校准说明**：V=4 表示足以提出针对性复核方案，不代表实验严谨、数据真实或产品有效。是否随机排序、计时方法和质量变化仍值得检查。低分不等于无须追问。

**直白解释**：一次小范围回放测试中，助手参与后的平均处理时间较短，但质量和线上效果还不清楚。

**追问**：两轮计时方式和人员是否一致，如何控制熟悉样本的影响？草稿质量怎样评估？上线后人工确认的耗时如何计入？

## /translate 补充

原文已经较具体。可简写为：“上周，我们用同一组 40 条历史工单测试草稿助手，平均处理时间从 10 分钟降到 8 分钟；发送仍需客服确认，质量和线上效果尚未验证。”不要改写为“AI 已提高客服效率 20%”，那会丢失测试范围与质量限制。

## 反例：引用不是认可

输入：“我不同意‘不用 AI 就会被淘汰’，这句话没有交代适用条件。”

评分对象应为反驳句的实际主张；被否定的威胁不计入 A，不能据命中“淘汰”判高风险。若只提供“‘不用 AI 就会被淘汰’这句话怎么理解？”而对象不清楚，应明确是在分析引文形式，不能归因于提问者。

## 反例：无有效主张

输入：“Agent、MCP、LLM、Skill”。

输出：“无法评分：这只是术语清单，没有需要评价的主张。请提供它们在文章或发言中的完整用法。”不得给出“黑话浓度 100”。
