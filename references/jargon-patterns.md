# 术语、权威与时代包装

本文件是语境提示，不是命中即扣分的词库。分值只按 evaluation-rubric.md 决定。

| 表达 | 何时需要进一步检查 | 合理反例 |
|---|---|---|
| Agent / Agentic Workflow / 智能体 | 不交代执行对象、动作和边界，却声称重构一切 | “助手先分类工单，再草拟回复，由客服确认” |
| MCP | 只用名称替代工具连接方案的说明 | 在技术讨论中准确说明组件交互、权限和失败处理 |
| LLM / 大模型 / 多模态 | 将模型名称等同于业务已获益 | 说明模型处理什么输入、输出及验收条件 |
| Skill / 数字员工 / All in | 名称叠加后仍无法复述实际任务 | “这份 Skill 按六个维度检查用户提供的文字” |
| 认知差 / 范式变化 / 组织重构 | 无法指认哪一步、谁的职责发生了变化 | 清楚描述调整前后流程和职责 |

## 权威借力 R

“某大厂都下场了”“大咖都认同”“与我半年前判断不谋而合”仅作为检查提示。问：它是在介绍背景，还是在代替结论所需的论证？自我背书默认也不能直接按专家背书最高档计分。

反例：“这是我三个月前的预测记录；当时估计 10%，这次观察为 8%，样本仅限内部用户。”这提供了可检查的比较，不应仅因提到自己而增加 R。

## 时代宣言 T

“新时代来了”“终局已定”“唯一道路”“一切都将重写”需要检查范围、条件和根据。对未来趋势的有条件推测不等于包装；“在我们的客服试点里，草稿生成方式发生了变化”不是全球时代宣言。

翻译时将不明确术语标成待确认项，不把所有 Agent 都翻译成固定规则自动化，也不把不同技术概念硬说成同一种东西。
