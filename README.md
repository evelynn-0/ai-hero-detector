# AI Hero Detector / AI 之星鉴定器

**把“时代真的来了”拆成可以追问、可以验证的具体主张。**

v0.2.0 · 自定义署名许可 · 中文优先 · 无强制联网、无 API 密钥依赖

> Judge the claim, not the person. 只评价文本与观点，不评价具体个人。

输入一段 AI 圈文章、朋友圈、会议发言或口播稿，获得带原文证据的 **0–100 AI 之星指数**，或者把黑话翻译成人话、生成项目澄清问题、创作明确标注的讽刺段子。

这是由 AI 助手执行的 **Skill（可复用指令包）**，不是独立应用，也不是事实核查器。指数是按公开规则归纳的话术特征，未经统计验证；不是“说谎概率”、科学测量或人物评级。同一文本在不同模型上可能出现评分差异。

## 四种模式

| 输入方式 | 输出 | 适合什么时候用 |
|---|---|---|
| `/detect` + 文本 | 指数、六维得分、原文证据、校准说明、追问 | 看清一段话说了多少实质内容 |
| `/translate` + 文本 | 直白改写、缺失信息、一个关键问题 | 将抽象表达转成可讨论的需求 |
| `/challenge` + 文本 | 按优先级排列、可验收的澄清问题 | 项目讨论、会议准备 |
| `/generate-ai-star` + 主题 | 标明虚构的 AI 圈讽刺文案 | 视频演示、内容创作 |

这些斜杠名称是本 Skill 识别的文本约定，不会自动注册为宿主软件的按钮或命令。普通中文指令也可以触发，例如“用 AI 之星鉴定器分析下面这段话”。

## 快速开始

1. 下载并解压，保留整个 `ai-hero-detector/` 文件夹。
2. 在支持文件型 Skills 的 AI 助手中，按该助手的安装入口加载整个文件夹。不同产品的目录和安装入口不同；本项目不承诺一键兼容全部产品。
3. 首次使用可以明确说：**“使用 ai-hero-detector，/detect 以下文本：……”**
4. 若助手没有 Skill 安装入口，可提供整个项目文件，并要求它先读 `SKILL.md`，再按相应模式读取引用文件。如果只支持文本粘贴，请粘贴 `SKILL.md` 和该模式要求的参考文件；只粘贴 README 不能执行完整评分。

此压缩包不会自动安装任何内容。基础工作流不需要代码执行，也不会自行上传、发布或查找作者。使用在线 AI 助手时，你提供的文本仍由该助手处理；请先移除内部项目、客户和个人敏感信息。

### 一分钟试用

```text
使用 ai-hero-detector
/detect
今天必须立刻 All in Agentic Workflow：因为 Agent 就是数字员工、不必再问怎么运作，不这样做就必然被淘汰，某峰会大咖都赞同这个决定所以肯定没错，而且新时代已不可逆地到来。
```

按项目示例的分段和校准，结果为 **91/100，宣言与包装很密集**。完整证据见 [示例 01](examples/example-01.md)。

对应的具体表达可以是：

> 在上周的内部测试中，工单助手只生成回复草稿，由客服确认后发送；同一组 40 条历史工单的平均处理时间从 10 分钟变为 8 分钟，质量尚未评估，也未验证线上收益。

本项目示例给它 **0/100**，因为表达提供了范围、过程、比较和局限；这不代表测试数据已被核实。见 [示例 02](examples/example-02.md)。

## 指数怎么来

| 维度 | 权重 | 高分含义 |
|---|---:|---|
| J 黑话浓度 | 20% | 术语堆叠挤占了具体说明 |
| M 比喻替代原理 | 15% | 用类比代替机制，甚至阻断追问 |
| A 焦虑贩卖 | 20% | 无条件地宣称不采用就会落后或被淘汰 |
| R 权威借力 | 15% | 用身份、热度或自我背书代替论证 |
| T 时代宣言 | 15% | 无边界地预告全面、必然的时代转折 |
| V 可验证信息密度 | 15%（反向计入） | 高分表示文本提供更多可检查细节 |

每项原始分为 0–4；V 越高，最终指数越低。逐主张评分后等权平均。详细触发规则、反例、计算方式与误伤校准见 [评分规范](references/evaluation-rubric.md)。没有可评分主张时返回“无法评分”，不伪造 0 分。

可选的 [本地计分器](scripts/score.py) 只负责计算人工或模型标注后的分数，不会读懂文本。需要 Python 3，无第三方依赖：

```sh
python3 scripts/score.py examples/annotations-01.json
python3 -m unittest discover -s tests
```
